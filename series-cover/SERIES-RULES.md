# ju.sijeom 릴스 커버 통일 규칙 (2026-11-16 ~)

미주님 요청: 피드에서 릴스가 한눈에 같은 시리즈로 보이게. 참고 이미지 2장은 '분위기 원리'만 사용(문구·사진·브랜드 복제 금지).
매일 릴스 제작(07:52 / 18:00 주제 작업 포함)은 커버·첫 장면을 이 규칙으로 만든다.
렌더러: `cardnews/series-cover/render.js` (COVERS 배열에 한 줄 추가 → `node render.js`). 샘플: `samples/`.

## 색 (2026-11-17 미주님 선택: 진한 네이비 + 연핑크, 이 4색만)
| 이름 | 값 | 쓰임 |
|---|---|---|
| 네이비 | #16264A | 컬러형 배경, 사진형 그늘(shade) 색, 라벨 |
| 소프트 화이트 | #FBF4F3 | 컬러형 밝은 배경 |
| 연핑크 | #F7C6D3 | 핵심어 하이라이트 박스(네이비 글자), 보조줄(어두운 배경), 별 |
| 진한 핑크 | #D9627F | 로고 점, 밝은 배경일 때 보조줄·별 |
- 예전 초록빛 남색(#0F3A4B)·노랑·코랄은 쓰지 않는다. 릴스마다 포인트 색을 바꾸지 않는다.
- 사진형 그늘은 검정 대신 네이비 계열(rgba(15,27,54,…)) → 사진이 달라도 피드 톤이 같다.

## 틀 2종
- **A 사진형 (기본)**: 주제를 그대로 보여주는 실사진 전면 + 네이비 그늘. 장소·제품·상황이 사진으로 잘 보일 때.
- **B 컬러형**: 네이비 또는 소프트 화이트 단색 배경 + 오른쪽 아래 캡슐 모양 사진(400×560, 둥근 모서리). 체크리스트·정리법·숫자 정보처럼 글이 주인공일 때, 또는 사진이 약할 때.
- 피드 리듬: 사진형 2편에 컬러형 1편 정도로 섞고, 컬러형은 네이비/화이트를 번갈아.

- 제목은 2줄 고정. 넘치면 문구를 줄인다(글자 크기 줄이지 않기).

## 문구
- 제목 = 구체 숫자/대비 + 말끝(~대요, ~하세요, ~다면?). 핵심어 1개만 박스.
- 근거 없는 '충격/무조건' 금지, 본편에 없는 내용(숫자·시간)을 커버에 새로 넣지 않기.
- 해시태그는 커버에 넣지 않는다(캡션에).
