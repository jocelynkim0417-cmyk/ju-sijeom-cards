# ju.sijeom 릴스 커버 통일 규칙 (2026-11-16 ~)

미주님 요청: 피드에서 릴스가 한눈에 같은 시리즈로 보이게. 참고 이미지 2장은 '분위기 원리'만 사용(문구·사진·브랜드 복제 금지).
매일 릴스 제작(07:52 / 18:00 주제 작업 포함)은 커버·첫 장면을 이 규칙으로 만든다.
렌더러: `cardnews/series-cover/render.js` (COVERS 배열에 한 줄 추가 → `node render.js`). 샘플: `samples/`.

## 색 (프로필 v2·하이라이트 커버와 같은 팔레트, 이 4색만)
| 이름 | 값 | 쓰임 |
|---|---|---|
| 남색 navy | #0F3A4B | 컬러형 배경, 사진형 그늘(shade) 색 |
| 크림 cream | #F6F1EA | 컬러형 밝은 배경 |
| 노랑 yellow | #FFD43B | 핵심어 하이라이트 박스, 보조줄(어두운 배경), 별 |
| 코랄 coral | #FF4F6D | 로고 점, 크림 배경일 때 보조줄·별 |
- 릴스마다 포인트 색을 바꾸지 않는다 (예전처럼 주황·파랑·빨강 태그 금지).
- 사진형 그늘은 검정 대신 남색 계열(rgba(10,42,55,…)) → 사진이 달라도 피드 톤이 같다.

## 틀 2종
- **A 사진형 (기본)**: 주제를 그대로 보여주는 실사진 전면 + 남색 그늘. 장소·제품·상황이 사진으로 잘 보일 때.
- **B 컬러형**: 남색 또는 크림 단색 배경 + 오른쪽 아래 캡슐 모양 사진(400×560, 둥근 모서리). 체크리스트·정리법·숫자 정보처럼 글이 주인공일 때, 또는 사진이 약할 때.
- 피드 리듬: 사진형 2편에 컬러형 1편 정도로 섞고, 컬러형은 남색/크림을 번갈아.

| 요소 | 위치·크기 |
|---|---|

| 작은 라벨 | y470, 진한 사각 라벨(흰 글자 40px) — 상황·대상 한 줄 |
| 제목 | 2줄, 112px ExtraBold, 왼쪽 정렬. 핵심어만 노란 하이라이트 박스(남색 글자) |
| 보조줄 | 제목 아래 50px, 노랑(크림 배경이면 코랄) — 질문·말끝 훅 |
| 핸들 `@ju.sijeom` | 왼쪽 아래 y1590 |
| 별 포인트 | 사진형: 오른쪽 아래 / 컬러형: 왼쪽 중간(캡슐 사진 옆) |
| 사진 출처 | y1730 작은 글씨 (그리드 밖) |
- 프로필 그리드 영역 y240~1680 안에 로고·제목·핸들이 모두 들어간다. 제목 블록은 y1000 안에서 끝난다(렌더러가 자동 점검).
- 제목은 2줄 고정. 넘치면 문구를 줄인다(글자 크기 줄이지 않기).

## 문구
- 제목 = 구체 숫자/대비 + 말끝(~대요, ~하세요, ~다면?). 핵심어 1개만 박스.
- 근거 없는 '충격/무조건' 금지, 본편에 없는 내용(숫자·시간)을 커버에 새로 넣지 않기.
- 해시태그는 커버에 넣지 않는다(캡션에).
